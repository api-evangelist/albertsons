# Albertsons Companies

> Albertsons Companies, Inc. is one of the largest food and drug retailers in the United States, operating supermarkets and pharmacies under the Albertsons, Safeway, Vons, Jewel-Osco, Acme, Shaw's, Star Market, Randalls, Tom Thumb, Pavilions, Carrs and Haggen banners. Its retail media network, Albertsons Media Collective, sells advertising against shopper purchase behavior across those banners.

## API status — read this before attempting an integration

Albertsons Media Collective announced an advertiser-facing API on 2025-01-07,
alongside a TransUnion marketing-mix-modeling partnership. The announcement says
the API gives Media Collective clients near-real-time access to campaign
performance data so they can pull it into their own measurement models, and that
it is available to all participating advertisers.

There is no way for an agent, or a developer, to reach it today:

- Access is contractual. The API is offered to Albertsons Media Collective
  advertisers, agencies and measurement partners under a media agreement. There
  is no self-serve signup, no public API key issuance and no free tier.
- There is no reachable developer portal. The Azure API Management portal at
  portal-prod.apim.azwestus.stratus.albertsons.com is indexed by search engines
  but does not resolve — the entire stratus.albertsons.com DNS zone returns
  SERVFAIL from every public resolver tested on 2026-08-13.
- There is no reachable API host. api.albertsons.com resolves to a decommissioned
  MyWebGrocer address with TCP 80 and 443 filtered; every request times out.
- There is no published machine-readable contract. No OpenAPI, Swagger, GraphQL
  SDL, AsyncAPI, MCP server, agent card, or /.well-known/ document was found on
  any Albertsons host.
- There are no first-party SDKs on npm, PyPI or GitHub, and no Albertsons GitHub
  organization.

The OpenAPI files in this repository were modeled by API Evangelist from press
coverage of the announcement. They are marked `x-generated-from: documentation`.
Do not treat them as an Albertsons contract, and do not call the host they name.

## How to get access

- Albertsons Media Collective: https://www.albertsonsmediacollective.com — contact
  the Media Collective team through the site. API access follows an advertising
  agreement, not a developer signup.
